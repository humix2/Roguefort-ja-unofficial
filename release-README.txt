Roguefort 非公式日本語化パッチ 2026.10.26
（ゲーム v0.34.2 向け）

ファンが作った非公式の日本語化です。開発元とは関係ありません。
不具合が出ても開発元には問い合わせず、まず英語版に戻して確認してください。


■ インストール
1. Roguefort を終了する。
2. このフォルダの install.bat をダブルクリックする。
   Steam のインストール先から Roguefort を自動で探して日本語化します（1〜2分）。
3. 「インストール完了」と出たら、ゲームを起動する。

ゲームが見つからないと言われたときは、Roguefort のフォルダ
（Steam でゲームを右クリック → 管理 → ローカルファイルを閲覧）を
install.bat にドラッグ＆ドロップしてください。


■ ゲームが更新されたとき
Steam がゲームを更新すると、ゲームは英語に戻ります。
install.bat をもう一度実行すれば日本語化し直せます。
このパッチより新しいバージョンで追加・変更された文は英語のまま表示されます。


■ 英語に戻す（アンインストール）
uninstall.bat をダブルクリックしてください。
または Steam でゲームを右クリック → プロパティ → インストール済みファイル →
「ゲームファイルの整合性を確認」でも英語版に戻ります。


■ しくみ
ゲームの resources\app.asar（ゲームの中身）の表示文を日本語に書き換えます。
・英語の原本は resources\app.asar.roguefort-ja-backup として残します（約700MB）。
・状態は resources\roguefort-ja.json に記録します。
・アンインストールすると、どちらも削除します。
・セーブデータには触れません。
名前（地名・アイテム名・本の題名など）は英語のままにしています。
ゲームの中で生成されて保存された文（拾った本の本文など）は、生成したときの言語のままです。


■ 注意
・ゲーム側でファイルの改ざんチェックが有効になると、このパッチは使えなくなります。
・同梱の node フォルダは、インストーラーを動かすための Node.js です（ライセンスは LICENSES.txt）。
